**TRON: Evolution Patcher** — легковесный инструмент бинарной модификации для игры *TRON: Evolution* (Unreal Engine 3, 32-bit x86). Включает нативный рендеринг через **Vulkan** (DXVK 3.1.1) с возможностью мгновенного отката на **DirectX 9**, разблокировку частоты кадров (до 120/144/165/200 FPS), кастомные разрешения (2K/4K/DLDSR) и 100% портативность без реестра Windows и без папки «Мои Документы».

### Почему стоит использовать этот патчер?

- **Плавный фреймрейт без микрофризов (Vulkan / DXVK 3.1.1):** Нативный DirectX 9 в старых играх страдает от просадок и задержек ввода на современных GPU. DXVK транслирует вызовы D3D9 в современный Vulkan API, обеспечивая стабильный frametime и максимальную отзывчивость управления.
- **Хирургический IAT-патч (всего 8 байт):** Патчер не внедряет тяжёлые инжекторы и хуки памяти. В таблице импорта PE исполняемого файла `GridGame.exe` заменяется ровно 8 байт (`d3d9.dll\0` ↔ `vk09.dll\0`). Длина имени одинаковая, структура PE-заголовков и контрольные точки не смещаются.
- **Разблокировка частоты кадров (FPS Unlock) с защитой физики:** Движок UE3 по умолчанию жёстко ограничен 62 FPS. Патчер позволяет безопасно выставить 120, 144, 165 или 200 FPS для высокогерцовых игровых мониторов без поломки скриптов и светоциклов.
- **100% Portable (Автономный запуск):** Игра запускается автономно без привязки к системному реестру Windows и без необходимости прав администратора. Идеально для переноса на другие ПК, внешние диски и USB-накопители.
- **Полная изоляция сохранений и настроек (папка UserData):** Внедрён 432-байтный автономный Code Cave, который рекурсивно перенаправляет создание профилей, логов (`Launch.log`), конфигураций (`.ini`) и чекпоинтов (`CHECKPT`) в каталог `<GameRoot>\UserData`. В системных «Моих Документах» игра больше не оставляет мусора.
- **Безопасность и 1-Click Rollback:** Автоматически создаётся чистая резервная копия `GridGame.exe.bak_d3d9`. Вернуть оригинальный нативный DirectX 9 можно в один клик.

### Главные возможности:

- ⚡ **Переключение графического API в один клик** — мгновенный выбор между Vulkan и DirectX 9.
- 🎯 **Управление частотой кадров (FPS Limiter)** — пресеты 62, 120, 144, 165, 200 FPS или снятие лимита, а также произвольный ввод.
- 🖥️ **Настройка любого разрешения (Pure .INI)** — 2K QHD (2560x1440), DLDSR (2880x1620), 4K UHD (3840x2160), Full HD и другие без сброса движком при выходе (атрибут Read-Only).
- 🚀 **Автономность и портативность** — отвязка от реестра и перенос папки сейвов прямо в корень игры.
- 📊 **Оверлей DXVK HUD** — отображение FPS, температуры, загрузки GPU и видеопамяти VRAM.
- 🎨 **Принудительная анизотропная фильтрация 16x** — кристальная чёткость текстур через шейдерные сэмплеры DXVK.
- 🔍 **Автопоиск игры** — автоматическое нахождение папки с игрой на диске.
- ▶ **Прямой запуск игры** — запуск игры прямо из интерфейса.

### Быстрый старт:

1. Скачайте архив `TronEvolutionPatcher-1.0.0.zip` в разделе [Releases](https://github.com/codomagia/Tron-Evolution/releases/latest).
2. Распакуйте архив целиком в любое удобное место (или в папку с игрой), сохранив папку `Assets` рядом с EXE.
3. Запустите `TronEvolutionPatcher.exe`.
4. Патчер автоматически найдёт установку игры (или нажмите **«Обзор…»** и укажите папку).
5. Нажмите **«⚡ Переключить на Vulkan»**, выберите желаемое разрешение, FPS и нажмите **«💾 Применить настройки»**.
6. Нажмите **«▶ Запустить игру»**!

## Системные требования

- **ОС:** Windows 10 или Windows 11 (64-bit)
- **Платформа патчера:** C# / WPF, .NET Framework 4.7.2 или совместимая более новая версия runtime
- **Видеокарта:** Любая видеокарта с поддержкой Vulkan 1.3+ (NVIDIA GeForce 900+, AMD Radeon RX 400+, Intel Arc / Iris Xe)
- **Целевая игра:** TRON: Evolution (версия Win32Live)
