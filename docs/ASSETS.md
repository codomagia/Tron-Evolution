# Ресурсы сборки

Из `TronEvolutionPatcher 1.0.1/assets` скопированы без изменений:

| Файл | Использование |
| --- | --- |
| logo.png | Встроенный ресурс заголовка WPF |
| app.ico | Иконка EXE и окна, встроенный ресурс |
| vk09.dll | Payload в Assets рядом с EXE |

SHA256 vk09.dll: `265888c31ca78dffa290c39cb7e50bfb02762590e41927906e46fb32f01497fa`.
Тест проверяет этот отпечаток и структуру x86 DLL с экспортом Direct3DCreate9 без её исполнения.

Проект распространяется по исходной MIT-лицензии CodoMagia. Она копируется в выходную папку как LICENSE.txt.
Для DXVK включён неизменённый текст [лицензии upstream](https://github.com/doitsujin/dxvk/blob/master/LICENSE)
в Assets/LICENSE.dxvk.txt; источник получен 2026-10-19.
Не утверждается отдельная проверка номера версии DLL: подтверждена идентичность ресурсу исходного патчера.

Пользовательский ZIP содержит только EXE и Assets/vk09.dll. Полные тексты лицензий также встроены в EXE как ресурсы TronEvolutionPatcher.Licenses.MIT.txt и TronEvolutionPatcher.Licenses.DXVK.txt; отдельные лицензионные файлы остаются в исходниках, выходной папке сборки и материалах публикации. При переносе готового пакета сохраняйте папку Assets с DLL рядом с EXE.
Внешние графические библиотеки и Python для WPF-сборки не нужны.
