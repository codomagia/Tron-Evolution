# TRON: Evolution Patcher 1.0.0

## Included

- DirectX 9 / Vulkan switching, DXVK HUD and anisotropic filtering.
- Graphics, FPS and language settings.
- No-Registry, UserData and profile migration.
- Executable backup, compatibility checks, file error rollback and an operation log.

## Installation

Extract the entire `TronEvolutionPatcher-1.0.0.zip` archive and run the EXE from the extracted folder. The patcher needs no installer; .NET Framework 4.7.2 or a compatible runtime must be installed.
